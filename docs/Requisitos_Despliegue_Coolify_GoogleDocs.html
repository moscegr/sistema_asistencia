📄 Requisitos de Despliegue en Coolify (Docker)

Sistema de Control de Acceso y Gestión Escolar | Stack: Spring Boot 3.4 (Java 17) + MongoDB 7.0 + Traefik

1. Requisitos del Servidor (VPS / Instancia Cloud)

Recurso Requisito Mínimo (Pruebas) Requisito Recomendado (Producción +1,500 Alumnos)
Sistema Operativo Ubuntu Server 22.04 LTS (x86_64) Ubuntu Server 24.04 LTS (x86_64)
Núcleos de CPU 2 vCPUs 4 vCPUs
Memoria RAM 4 GB RAM (+ 2 GB Swap) 8 GB RAM (+ 4 GB Swap)
Almacenamiento 40 GB SSD / NVMe 80+ GB NVMe
Puertos de Red 80 (HTTP), 443 (HTTPS), 22 (SSH) 80, 443, 22 y 8000 (Panel Coolify)

2. Variables de Entorno en Coolify

Variable Valor / Ejemplo Propósito
SPRING_DATA_MONGODB_URI mongodb://admin_mongo:Password@mongodb:27017/residencia_cbtis?authSource=admin Conexión con MongoDB
APP_UPLOAD_DIR /app/uploads Ruta para almacenar fotos y credenciales
SPRING_SERVLET_MULTIPART_MAX_FILE_SIZE 50MB Tamaño máximo por archivo
SPRING_SERVLET_MULTIPART_MAX_REQUEST_SIZE 50MB Tamaño máximo del payload
ADMIN_EMAIL admin@admin.edu.mx Usuario administrador inicial
ADMIN_PASSWORD 12345678 Contraseña inicial encriptada con BCrypt

3. Volúmenes Persistentes (Storages en Coolify)

Volumen Ruta en el Contenedor (Mount Path) Descripción
app_uploads /app/uploads Fotos de alumnos, docentes y archivos subidos
mongo_data /data/db Base de datos de MongoDB

4. docker-compose.yml para Coolify

version: '3.8'

services:
  mongodb:
    image: mongo:7.0
    container_name: cbtis_mongodb
    restart: always
    environment:
      MONGO_INITDB_ROOT_USERNAME: \
      MONGO_INITDB_ROOT_PASSWORD: \
      MONGO_INITDB_DATABASE: residencia_cbtis
    volumes:
      - mongo_data:/data/db
    healthcheck:
      test: ["CMD", "mongosh", "--eval", "db.adminCommand('ping')"]
      interval: 10s
      timeout: 5s
      retries: 5

  app:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: cbtis_app
    restart: always
    depends_on:
      mongodb:
        condition: service_healthy
    environment:
      SPRING_DATA_MONGODB_URI: mongodb://\:\@mongodb:27017/residencia_cbtis?authSource=admin
      SPRING_SERVLET_MULTIPART_MAX_FILE_SIZE: 50MB
      SPRING_SERVLET_MULTIPART_MAX_REQUEST_SIZE: 50MB
      APP_UPLOAD_DIR: /app/uploads
      ADMIN_EMAIL: \
      ADMIN_PASSWORD: \
    volumes:
      - app_uploads:/app/uploads
    expose:
      - "8080"

volumes:
  mongo_data:
